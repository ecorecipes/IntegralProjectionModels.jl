Categorical Composition

Category-theoretic tools for composing, stratifying, and coarsening IPM kernels. These enable modular construction of complex models from simpler components.

StructuredPopulationCore.left_kan_extension — Function
left_kan_extension(kernel_fn, domain::ContinuousDomain)

Discretise a continuous kernel function kernel_fn(z_new, z) into a matrix using the midpoint rule on the given domain.

This is the left Kan extension along the discretisation functor: it maps a morphism in Krn (Markov kernels on measurable spaces) to a morphism in FinStoch (stochastic matrices on finite sets).

$A_{ij} = h \cdot K(z_i, z_j)$

where $h$ is the bin width and $z_i$ are the midpoints.

Arguments

  • kernel_fn: a callable (z_new, z) -> Real giving the kernel density
  • domain: a ContinuousDomain specifying bounds and mesh resolution

Returns

  • A::Matrix{Float64}: the discretised transition matrix

Keyword options (another quadrature rule, positivity) are implemented by CategoricalPopulationDynamics.jl; see discretise_kernel.

StructuredPopulationCore.right_kan_extension — Function
right_kan_extension(A::AbstractMatrix, domain::ContinuousDomain)

Construct a piecewise-constant kernel function from a matrix and domain.

This is the right Kan extension: the most conservative continuous representation of a discrete transition matrix. The resulting kernel is constant within each bin pair:

$K_{\mathrm{pw}}(z', z) = A_{ij} / h \quad \text{where } z \in B_j,\; z' \in B_i$

Arguments

  • A: an n × n transition matrix
  • domain: a ContinuousDomain with n meshpoints matching size(A, 1)

Returns

  • A callable (z_new, z) -> Real giving the piecewise-constant kernel density

StructuredPopulationCore.stratify — Function
stratify(A_local::AbstractMatrix, coupling::AbstractMatrix)

Construct a block-structured matrix from a single local transition matrix and a coupling (dispersal) matrix. Every stratum (patch, genotype, infection state) shares the same local dynamics.

In the categorical framework, this is a pullback in a slice category: the local demography is replicated across strata and weighted by the coupling.

$A_{\mathrm{strat}}[(s_{\mathrm{to}}, i),\, (s_{\mathrm{from}}, j)] = D[s_{\mathrm{to}}, s_{\mathrm{from}}] \cdot A_{\mathrm{local}}[i, j]$

Arguments

  • A_local: an n × n local (single-stratum) transition matrix
  • coupling: a p × p matrix of weights between strata, coupling[to, from]

Returns

  • an (n·p) × (n·p) block-structured matrix

StructuredPopulationCore.coarsen — Function
coarsen(A::AbstractMatrix, from_domain::ContinuousDomain, to_domain::ContinuousDomain)

Coarsen a fine transition matrix to a coarser resolution by aggregating bins.

This is the pushforward (left Kan extension) along the coarsening map $f\colon \mathrm{FinSet}(n_{\mathrm{fine}}) \to \mathrm{FinSet}(n_{\mathrm{coarse}})$. Each coarse bin collects contributions from the fine bins it contains.

The from_domain and to_domain must share the same [lower, upper] bounds. The number of fine bins must be an integer multiple of the number of coarse bins.

Arguments

  • A: an n_fine × n_fine transition matrix
  • from_domain: the fine ContinuousDomain
  • to_domain: the coarse ContinuousDomain

Returns

  • an n_coarse × n_coarse transition matrix

IntegralProjectionModels.compose_kernels — Function
compose_kernels(sub_kernels, domain::ContinuousDomain)

Compose sub-kernel functions additively and discretise onto the given domain.

This is the concrete evaluation of an undirected wiring diagram (UWD) without requiring Catlab: each sub-kernel shares the same trait axes, and the composition rule sums their contributions.

$K_{ij} = \sum_k h \cdot K_k(z_i, z_j)$

Arguments

  • sub_kernels: a NamedTuple, Dict, or iterable of (name, fn) pairs where each fn is a callable (z_new, z) -> Real
  • domain: a ContinuousDomain

Returns

  • K::Matrix{Float64}: the summed, discretised transition matrix

See also: compose_from_uwd for the form that takes a Catlab wiring diagram.

source
StructuredPopulationCore.compose_from_uwd — Function
compose_from_uwd(uwd, sub_kernels::Dict, domain)

Evaluate a Catlab undirected wiring diagram (UWD) with concrete sub-kernels: each box is looked up by name in sub_kernels, and the composition sums their contributions on the mesh of domain.

The core package only declares the function. Methods are added where Catlab is available: by the Catlab extension of IntegralProjectionModels.jl for a ContinuousDomain, and by CategoricalPopulationDynamics.jl for its own domains.

Arguments

  • uwd: a Catlab UWD (from @relation)
  • sub_kernels: a Dict{Symbol, Function} mapping box names to kernel functions
  • domain: the domain to discretise on

Returns

  • the composed, discretised transition matrix
