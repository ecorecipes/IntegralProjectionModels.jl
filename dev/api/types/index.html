Types & Traits

Trait types classify IPMs along several axes: simple vs. general structure, density dependence, stochasticity, and projection method.

IPM Structure

StructuredPopulationCore.AbstractIPMStructure — Type
AbstractIPMStructure

Compatibility supertype for the existing integral projection model structure names. It remains available as part of the shared abstraction layer so current IPM code can keep its API while new packages dispatch on the more neutral AbstractContinuousStateStructure.

source
StructuredPopulationCore.SimpleIPM — Type
SimpleIPM

Single continuous-state structure.

source
StructuredPopulationCore.GeneralIPM — Type
GeneralIPM

Multi-state or otherwise generalized continuous-state structure.

source

Projection Structure

StructuredPopulationCore.AbstractProjectionStructure — Type
AbstractProjectionStructure

Supertype for projection model structure traits. Subtypes include shared continuous-state structures plus package-specific specializations.

source
StructuredPopulationCore.DirectIteration — Type
DirectIteration

Iterate the population forward via matrix multiplication: n_{t+1} = K * n_t.

source
StructuredPopulationCore.EigenAnalysis — Type
EigenAnalysis

Compute eigendecomposition of the materialized kernel matrix. No iteration is performed; returns asymptotic quantities directly.

source

Density Dependence

StructuredPopulationCore.AbstractDensityDependence — Type
AbstractDensityDependence

Supertype for density dependence traits. Subtypes: DensityIndependent, DensityDependent.

source
StructuredPopulationCore.DensityIndependent — Type
DensityIndependent

Vital rates do not depend on population size or density.

source
StructuredPopulationCore.DensityDependent — Type
DensityDependent

Vital rates depend on current population size or density.

source

Stochasticity

StructuredPopulationCore.AbstractStochasticity — Type
AbstractStochasticity

Supertype for stochasticity traits. Subtypes: Deterministic, StochasticKernelResampled, StochasticParameterResampled.

source
StructuredPopulationCore.Deterministic — Type
Deterministic

No stochastic variation; vital rates and kernels are fixed across time steps.

source
StructuredPopulationCore.StochasticKernelResampled — Type
StochasticKernelResampled

Environmental stochasticity via resampling entire kernel matrices at each time step.

source
StructuredPopulationCore.StochasticParameterResampled — Type
StochasticParameterResampled

Environmental stochasticity via resampling parameters that generate kernels at each time step.

source
