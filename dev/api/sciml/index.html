SciML Interface

Integration with the SciML ecosystem, allowing IPMs to be expressed as discrete dynamical systems.

IntegralProjectionModels.to_discrete_problem — Function
to_discrete_problem(prob::IPMProblem)

Convert an IPMProblem to a SciMLBase.DiscreteProblem.

The resulting problem can be solved with OrdinaryDiffEq.FunctionMap() or similar discrete solvers from the SciML ecosystem.
