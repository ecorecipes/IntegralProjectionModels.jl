Vital Rates

Vital rates are the building blocks of IPM kernels. Each vital rate is a callable struct that maps individual state (e.g., body size) to a demographic rate or distribution.

Abstract Types

IntegralProjectionModels.AbstractVitalRate — Type

Abstract type hierarchy for vital rates.

All vital rate types are callable structs with plain numeric fields, making them compatible with automatic differentiation.

Survival Rates

Survival rates map individual state to a probability of surviving to the next time step.

IntegralProjectionModels.LinearSurvival — Type
LinearSurvival{T}

Survival probability as a logistic function of size: s(z) = logistic(intercept + slope * z).

source
IntegralProjectionModels.QuadraticSurvival — Type
QuadraticSurvival{T}

Survival probability with a quadratic term: s(z) = logistic(intercept + slope * z + quadratic * z^2).

source
IntegralProjectionModels.ConstantSurvival — Type
ConstantSurvival{T}

Constant survival probability independent of size.

source

Growth Rates

Growth rates describe the distribution of state transitions for surviving individuals.

IntegralProjectionModels.NormalGrowth — Type
NormalGrowth{T}

Growth kernel: g(z', z) = pdf(Normal(intercept + slope * z, sigma), z'). Transition from size z to size z' follows a normal distribution.

source
IntegralProjectionModels.LogNormalGrowth — Type
LogNormalGrowth{T}

Growth kernel using a log-normal distribution for size transitions.

source
IntegralProjectionModels.mean_size — Function
mean_size(g::NormalGrowth, z)

Expected size at next time step given current size z.

Fecundity Rates

Fecundity rates describe reproduction: the probability of reproducing and the distribution of offspring states.

IntegralProjectionModels.FecundityRate — Type
FecundityRate{T}

Combined fecundity kernel computing the probability of producing an offspring of size z' from a parent of size z:

f(z', z) = establishment_prob * exp(intercept + slope * z) * pdf(Normal(recruit_mean, recruit_sd), z')

source
IntegralProjectionModels.LogisticFecundityRate — Type
LogisticFecundityRate{T}

Fecundity where reproduction probability is logistic (e.g., flowering probability):

f(z', z) = logistic(repr_int + repr_slope * z) * exp(seed_int + seed_slope * z) * pdf(Normal(recruit_mean, recruit_sd), z')

source
IntegralProjectionModels.RecruitmentDistribution — Type
RecruitmentDistribution{T}

Distribution of recruit sizes, independent of parent size.

source

Custom Vital Rates

For user-defined vital rate functions that do not fit the built-in types.

IntegralProjectionModels.CustomVitalRate — Type
CustomVitalRate{F,P}

Wraps any callable as a vital rate. The function func is called as func(args...; params...) or simply func(args...).

Examples

# A size-dependent vital rate
vr = CustomVitalRate((z) -> 0.5 * z, nothing)
vr(1.0)  # 0.5

# With parameters
vr = CustomVitalRate((z, p) -> p.a + p.b * z, (a=1.0, b=0.5))
vr(2.0)  # calls func(2.0, (a=1.0, b=0.5))
